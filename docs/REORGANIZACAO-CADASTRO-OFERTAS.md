Reorganização da tela administrativa de cadastro/edição de ofertas

- Removido o banner roxo grande e repetitivo do formulário.
- Cabeçalho da página ficou mais limpo, com breadcrumb, título, explicação curta e botão para voltar.
- Criada navegação compacta das 7 etapas do cadastro com atalhos clicáveis.
- Mantido o formulário em duas colunas no desktop e responsivo no mobile.
- As etapas receberam âncoras para navegação rápida.
- O cabeçalho/navegação do painel administrativo agora usa fundo claro explícito, evitando o bloco escuro que aparecia na tela.
- A mesma organização foi aplicada à tela de editar oferta para manter consistência.
- Nenhuma mudança no banco de dados é necessária para esta atualização.
