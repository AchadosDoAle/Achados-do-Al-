Atualização dos filtros de categorias da Home

- Substituída a longa fileira de chips por um menu compacto de categorias.
- O botão “Todos” continua disponível para voltar rapidamente à lista completa.
- O botão “Categorias” abre um painel pesquisável com todas as categorias cadastradas no painel administrativo.
- Cada categoria mostra a quantidade atual de ofertas.
- Categorias manuais criadas pela opção “Outras” também entram automaticamente no menu quando houver oferta publicada naquela categoria.
- O filtro de loja agora fica na mesma barra de filtros.
- Há botão “Limpar” quando categoria ou loja estiverem filtradas.
- O menu é responsivo: grade maior no desktop e painel compacto/rolável no mobile.
- A página pública /categorias também foi atualizada com a lista ampliada.
