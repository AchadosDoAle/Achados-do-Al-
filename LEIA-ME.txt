PATCH DO SITE — BUSCA DE IMAGEM PARA O APP ADMIN ANDROID

Por que este patch existe:
O Android não consegue ler com confiabilidade páginas de muitas lojas e links curtos por causa de redirecionamentos, anti-bot e páginas carregadas por JavaScript. O site já possuía uma rota de servidor muito mais robusta em /api/buscar-imagem. Este patch permite que o app administrativo autenticado use a MESMA rota com seu token Supabase.

O que muda:
- mantém o painel web funcionando por cookie;
- aceita Authorization: Bearer <token> do app Android;
- valida o token no Supabase e confirma admin_users no servidor;
- não expõe service role no APK;
- amplia aliases de campos de imagem e parâmetros de redirecionamento;
- mantém a cópia da imagem para o bucket ofertas quando possível;
- devolve finalUrl apenas como informação; o app preserva o link afiliado original.

COMO APLICAR
1. No projeto atual do site achadosdoale.com, substitua apenas:
   app/api/buscar-imagem/route.ts
2. Rode npm run typecheck e npm run build.
3. Faça commit/push e aguarde o deploy da Vercel.
4. Depois, no app Admin, use o patch FOTO-MULTILOJAS correspondente.

Nenhuma tabela, migration ou SQL é necessário.
