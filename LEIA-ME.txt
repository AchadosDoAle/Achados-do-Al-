PATCH IMPACT - SUBSTITUI META TAG POR SCRIPT

1. Extraia este ZIP.
2. Copie Aplicar-Impact-Script.ps1 para a pasta raiz do site (onde esta package.json).
3. Abra PowerShell nessa pasta e execute:
   powershell -ExecutionPolicy Bypass -File .\Aplicar-Impact-Script.ps1
4. Confira a diferenca em app/layout.tsx ou src/app/layout.tsx.
5. Nao inclua o arquivo .impact.bak no commit.
6. Faca Commit e Push origin no GitHub Desktop.

O script remove a meta impact-site-verification antiga e adiciona
o script Impact solicitado ao head do layout, sem substituir o restante.
O script remoto podera transformar links e rastrear impressoes;
verifique suas preferencias de consentimento e politica de privacidade.
Este patch nao resolve outros erros de build do projeto.
